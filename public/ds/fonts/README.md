## Fichiers

| Fichier | Graisse | Usage |
| --- | --- | --- |
| `jetbrains-mono-400.ttf` | 400 (Regular) | Corps de texte, détails techniques (mono) |
| `jetbrains-mono-500.ttf` | 500 (Medium) | Graisse intermédiaire (optionnelle) |
| `jetbrains-mono-700.ttf` | 700 (Bold) | Titres |

Les sous-ensembles proviennent de la distribution Google Fonts de JetBrains
Mono. Le chargement est auto-hébergé via [`../fonts.css`](../fonts.css)
(déclarations `@font-face`), sans dépendance CDN.
